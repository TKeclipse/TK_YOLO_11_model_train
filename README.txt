YOLO Damage Detection Training Pipeline
This project implements a full training pipeline for building a high‑quality YOLO‑based car‑damage detector using a combination of:
• 	SAM (Segment Anything Model) auto‑labeling
• 	YOLO auto‑labeling
• 	Label filtering
• 	Iterative self‑training
• 	Final YOLO model export
The workflow is designed to progressively improve dataset quality and produce a strong, production‑ready model.

The full training loop consists of the following stages:
1. 	Generate initial labels using SAM
2. 	Filter noisy SAM labels
3. 	Train YOLO on the cleaned dataset
4. 	Use the trained YOLO model to auto‑label images
5. 	Retrain YOLO using improved labels
6. 	Validate and export the final model
Each stage is handled by a dedicated script.

Scripts and Execution Order
Below is the correct order in which each script should be executed, along with an explanation of what it does.

auto_sam_label.py — Generate initial labels using SAM
Purpose:
Use the Segment Anything Model (SAM) to automatically generate segmentation masks and convert them into YOLO bounding boxes.
What it does:
• 	Loads SAM (vit_b or vit_h)
• 	Generates masks for each image
• 	Converts masks → bounding boxes
• 	Saves YOLO TXT label files
Run this first to bootstrap your dataset.

filtering_txt_files.py — Clean noisy SAM labels
Purpose:
SAM produces many irrelevant masks (shadows, reflections, tiny fragments).
This script removes:
• 	very small boxes
• 	very large boxes
• 	extremely thin boxes
• 	unrealistic aspect ratios
What it does:
• 	Reads each SAM TXT file
• 	Applies geometric filters
• 	Saves only valid bounding boxes
This step dramatically improves dataset quality.

train_yolo.py — First YOLO training
Purpose:
Train YOLO on the cleaned SAM dataset to produce the first usable model.
What it does:
• 	Loads YOLO (starting from pretrained weights or previous best.pt)
• 	Trains on your dataset
• 	Validates the model
• 	Exports ONNX
This produces your first .

auto_labeling_no_sam.py — YOLO auto‑labeling
Purpose:
Use your trained YOLO model to generate better labels than SAM.
What it does:
• 	Loads your
• 	Runs inference on all training images
• 	Saves YOLO TXT labels generated by YOLO itself
These labels are cleaner and more consistent than SAM.

yolo_dataset_auto_labels.py — Alternative YOLO auto‑labeling (batch mode)
Purpose:
Another method to auto‑label using YOLO’s built‑in  function.
What it does:
• 	Runs YOLO on a folder
• 	Saves TXT labels automatically
• 	Saves predictions in a project folder
You can use either this script or the previous one.

train_yolo.py (second run) — Retrain YOLO with improved labels
Purpose:
Train YOLO again, but this time using the YOLO‑generated labels, which are cleaner than SAM.

This is the self‑training loop that boosts model accuracy.
